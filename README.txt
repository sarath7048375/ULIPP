# INL September 2026 Website Prototype

Open `index.html` in a browser.

This first prototype encodes the clearly extractable product-credit and incentive rules from the uploaded September 2026 PDF. It is intentionally structured so additional PDFs/products can be merged into the same calculation engine later.

Important: image-heavy commission tables (especially the detailed First Year Commission and Renewal Year Commission pages) are not guessed where the PDF extraction did not provide sufficiently reliable row/column data.
